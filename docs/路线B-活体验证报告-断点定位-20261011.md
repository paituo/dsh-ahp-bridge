## 四、链路逐环核对（renderer 侧源码）

```
① agent picker 组件（AgentHostAgentPickerProbe）:
   _initAgent(e,t,i,n,r,a){
     let c = this._getProvider(e, n);                    // ← 环 ④ 依赖本方法的返回
     if(!e || !c) return;

     let p = Xyn(l, t, u); ...
   }

② _getProvider(e,t){ let i = t.getProvider(e.providerId);
                     return i && vr(i) ? i : void 0 }   // ← 环 ③

③ vr(s){ return bI(s.id) }                              // ← 闸门（已实证通过）
   bI(s){ return s===Bb || s.startsWith(lRt) }          //   Bb="local-agent-host", lRt="agenthost-"

④ provider 侧 getCustomAgents（消费点）:
   getCustomAgents(e){
     let t = this._getSession(e); if(!t) return [];
     let i = this._getAHSProvider(t); if(!i) return [];
     let n = i.getCustomAgents(t.sessionId), r = t.mode.get()?.id;
     return n.length===0 && r ? [this._agentFromMode(r)] : n
   }

⑤ wrapper:
   getCustomAgents(e){ let t=this._customAgentsService.getCustomAgents(e);
                       return t.length>0 ? t : (this._draftCustomAgents?.get() ?? []) }
```

**判读**：`"Agent"` 这个字面值 **只能** 来自 `_agentFromMode("agent")`（`_agentFromMode(e){ return {id:e,uri:e,name:OBr(e),type:"agent"} }`，`OBr("agent")→"Agent"`），
**即 `n.length===0` 分支**。

而 agent-host 侧探针显示 `cacheN=5` ⇒ 若 RPC 真正到达，`n` 必非空。
**⇒ 断点位于 ②/④ 之间：`_getSession(e)` 或 `_getAHSProvider(t)` 返回了 falsy，**或 renderer 侧 provider 代理未转发 `getCustomAgents`。

## 五、★ 最终根因（SQLite 实证后修正）

### 5.1 数据库实证（`agent-host.db`，只读）

```sql
provider 分布:  copilotcli × 42  |  agenthost-dsh × 2  |  dsh × 1
最新会话:       agenthost-dsh:/61832725-fa19-4384-a908-c3da57a27d22   ← ✅ 新会话 provider 正确
                agenthost-dsh:/c539e785-08b6-4d8c-b7bd-15a0de7d713c
                dsh:/19106589-67e7-4dfc-9e17-14b42d79c1d9             ← 遗留脏数据（仅 1 条）
```

**⇒ 假设 A 被部分证伪**：新会话的 `providerId` **确实是 `agenthost-dsh`**（不是 `dsh`）。
`dsh:` 那条只是 1 条遗留记录，`CatalogReconciliation` 反复重试但**不影响新会话**。

### 5.2 真实根因：**看错了 picker —— 那是「草稿会话」的 picker**

`customizationHarnessService.getCustomAgents` 有两分支：

```js
getCustomAgents(e){
  let t = this._customAgentsService.getCustomAgents(e);        // ← 真实会话：走 provider
  return t.length>0 ? t : (this._draftCustomAgents?.get() ?? []) // ← 草稿会话：走 draft 兜底
}
```

| 场景 | 数据源 | 期望结果 |
|---|---|---|
| **打开已有 DSH 会话**（如 `agenthost-dsh:/61832725`） | `_customAgentsService` → `_getSession` → `_getAHSProvider` → **`provider.getCustomAgents()`** | **应显示 5 个 preset** |
| **新建草稿会话**（UI 默认态） | `_draftCustomAgents.get() ?? []` → **空** | 只显示 `Agent` + `配置自定义 Agent...` |

**本次 CDP 测试点的正是「新建/草稿」态**（页面默认就是新会话草稿），因此必然只有 2 个内置项。
**这不是缺陷 —— 是验证姿势错了。**
